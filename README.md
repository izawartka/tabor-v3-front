# tabor-v3-front

A simple frontend for my railway photo gallery, built with React, TypeScript, and styled-components.

**Live version:** https://maseuko.pl/txt/tabor/v3/

![Gallery Image](https://maseuko.pl/res/tabor-v3.jpg)

## Features

- Clean and responsive design
- API data caching and prefetching
- Smooth image loading with placeholders and thumbnails
- Infinite scrolling
- High test coverage

## Development

```bash
npm install
npm run dev
```

### Useful commands

- `npm run lint` - run ESLint to check for code issues
- `npm run format` - run Prettier to format code
- `npm run test` - run tests with Vitest

## Building

```bash
npm run build:prod
```
